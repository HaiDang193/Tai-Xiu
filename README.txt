TÀI XỈU DEMO (tiền ảo)

CHƠI BẢN WEB
  Bấm đúp index.html -> mở bằng Chrome là chơi được, không cần cài gì.

CHƠI BẢN CONSOLE (Python gốc)
  python taixiu.py

CẤU TRÚC
  index.html      khung trang
  css/style.css   giao diện, màu sắc (sửa màu ở :root đầu file)
  js/utils.js     hàm tiện ích + trạng thái game
  js/sound.js     âm thanh
  js/dice.js      xúc xắc 3D
  js/ui.js        hiển thị: số dư, nhật ký, pháo giấy, soi cầu
  js/game.js      sự kiện, nạp tiền, luật chơi
  taixiu.py       bản console gốc

PHÍM TẮT (bản web)
  T = chọn Tài, X = chọn Xỉu, Enter = Lắc
